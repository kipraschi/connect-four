# Connect Four

Command-line Connect Four built in Ruby using test-driven development. Part of The Odin Project Ruby curriculum.

## How to run

    ruby main.rb

## Running tests

    bundle install
    bundle exec rspec

## About

Built TDD-style with RSpec: tests were written before the implementation.
Game logic: Players take turns dropping pieces into a 7x6 grid, winning by connecting four in a row, column, or diagonal.
